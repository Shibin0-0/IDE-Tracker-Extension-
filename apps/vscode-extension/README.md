# @ide-usage-monitor/vscode-extension

Local-only IDE usage monitor extension for Visual Studio Code.

## Features (Planned)

- Captures active editor sessions and workspace switches.
- Tracks document modifications and active programming languages.
- Sends metrics directly to the local `tracker-service` (`127.0.0.1`).
- Completely offline: zero external telemetry, zero tracking scripts, zero cloud integrations.
