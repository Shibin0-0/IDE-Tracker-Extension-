# @ide-usage-monitor/antigravity-extension

Local-only IDE usage monitor extension/plugin for Antigravity.

## Features (Planned)

- Hooks into Antigravity workspace events and editor session lifecycles.
- Aggregates activity metrics and dispatches them to the local `tracker-service` (`127.0.0.1`).
- Completely offline: zero external telemetry, zero tracking scripts, zero cloud integrations.
